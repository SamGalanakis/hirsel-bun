hirsel / orchestration board

Warm Iron / Fast Amber

Hirsel inherits its visual language from lash — the same warm-black surfaces, sodium-amber markers, and ash-grey structure, adapted for a web-based orchestration board. The goal is a workshop control panel: information-dense, status-first, calm under long sessions.

01

The palette is intentionally narrow. Nearly every surface is warm black and chalk until sodium appears to signal intent, activation, or the active edge of work.

05

Principles

Rules that keep the UI coherent as new surfaces get added.

Accent Means Action

Sodium is reserved for the active edge: prompts, effort markers, status changes, and headings that matter.

Structure Before Ornament

Every border, divider, and container should clarify hierarchy before it tries to look good.

Density Over Sprawl

Compact spacing, small type, tight gaps. Information density beats generous whitespace in a dev tool.

Long Sessions Must Stay Calm

No high-saturation backgrounds, no fragile thin text, no ornamental overload. Survive hours of use.

Monospace Is the Default

UI chrome, labels, buttons, and inputs all use Chivo Mono. Spectral is only for editorial body text.

Zero Border Radius

No rounded corners anywhere. Sharp edges reinforce the workshop aesthetic.
