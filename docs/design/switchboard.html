Why this is interesting

Dispatch IS patching

Hirsel's dispatch system literally connects specs to workers — a switchboard operator patching cables. The metaphor is mechanically identical. "Ringing" is a spec needing dispatch. "In conversation" is a worker actively processing.

Cables show relationships

Colored cords from left to right visualize which worker is working on which spec. A completed cord changes color. A pulsing cord is actively being worked. Unpatched jacks are free resources or unassigned specs.

Lamps encode urgency

Lit = active work. Flashing = needs attention (ringing for dispatch). Dim = complete or idle. The lamp board gives you the system's attention state at a glance — just like a real exchange.

Shepherd as supervisor

The switchboard supervisor can listen in on any line — exactly what the shepherd console does when monitoring worker output. Tapping into a worker's "call" to check progress or intervene.
