WHY THIS IS INTERESTING

Four strokes = four phases

The four-stroke cycle maps perfectly to spec lifecycle: intake (draft, gathering requirements), compression (planning, decomposing into tasks), power (execution, workers firing), exhaust (delivery, pushing results out). Each phase has a distinct visual character.

The crankshaft connects

In an engine, the crankshaft converts individual piston motion into unified rotation. The route is this crankshaft — it ties independent spec cylinders into coordinated output. When one cylinder fires, it drives the whole system forward.

Misfires are visible

A misfiring cylinder is immediately obvious in a transparent engine — no combustion, no power stroke, the spark plug glowing wrong. Blocked or failed specs stand out the same way: the whole engine runs rougher when one cylinder is not contributing.

Gauges tell the system story

RPM, oil pressure, coolant temp — these are system-level metrics, not per-cylinder. They show whether the overall route is healthy, overheating, or losing pressure. Dashboard gauges naturally separate individual spec status from aggregate route health.
