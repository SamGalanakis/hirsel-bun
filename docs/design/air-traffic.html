WHY THIS IS INTERESTING

Dispatch = clearance

ATC's core job is granting clearances — which aircraft can approach, which must hold, which runway to use. Hirsel's dispatch does exactly this: which specs get workers, which must wait, which are complete.

Spatial awareness

A radar scope shows all traffic simultaneously with position, heading, and separation. A spec board should too — not as a list, but as a spatial field where proximity shows dependency and altitude shows progress.

Flight strips = persistent record

Real ATC uses paper flight strips next to the radar. Each strip has the aircraft's clearance, route, and status. The dual-panel layout gives both the spatial overview AND the detailed record.

The sweep arm

The rotating sweep reveals state periodically — like polling for updates. Blips brighten as the arm passes, then slowly fade. This creates a natural visual rhythm that matches hirsel's periodic status polling.
