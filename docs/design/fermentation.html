Fermentation

Each spec is a fermentation vessel. You look through the glass: bubbles rise (worker activity), sediment settles (completed tasks as lees), clarity increases (validation). The airlock pulses with each token spent. Time does the work.

Why this is interesting

Bubbles = worker activity

When a worker is active inside a spec, you see actual bubbles rising through the liquid. More workers = more bubbles. Idle specs are still. The movement IS the information — you don't need status labels.

Sediment = history

Completed tasks don't vanish — they settle to the bottom as lees. You can see the record of work that went into each spec. Dense sediment means lots of decomposed tasks. Light sediment means simple work.

Clarity = confidence

A spec starts turbid (cloudy, uncertain). As tasks complete and validation passes, it clarifies. A perfectly clear vessel = fully validated. You literally see the uncertainty leaving the system.

CO2 output = token cost

Fermentation produces CO2 as a byproduct. Workers produce token usage as a byproduct. The airlock bubbles with each inference call. High CO2 output means lots of LLM work happening — you can feel the cost.
