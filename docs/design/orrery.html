Orrery

Specs are planets orbiting a central route-sun. Inner orbits hold foundational work, outer rings the newest. Workers are moons circling their parent spec. Orbital speed reveals progress rate — fast means active, slow means blocked, stopped means draft. Validated specs ignite into stars.

Sun = Route

The gravitational center. All specs orbit the route intent. Its corona pulses with overall progress.

Planet = Spec

Inner orbits are foundational. Validated planets glow like stars. Working planets pulse amber. Draft planets are dark rock.

Moon = Worker

Workers orbit their claimed spec. Each moon is a parallel execution thread circling the task it transforms.

Why this is interesting

Hierarchy is distance

Foundational specs sit close to the route core. Dependent specs orbit further out. You see the dependency structure as spatial depth — inner work must complete before outer work has meaning, like gravity wells.

Progress is velocity

You don't read a progress bar — you feel it. A spec with active workers spins fast, its moons whipping around. A blocked spec crawls. A draft spec is frozen. Motion itself communicates state without any labels.

Parallelism is visible

Multiple moons orbiting a planet show multiple workers on one spec. Multiple planets spinning simultaneously show parallel spec execution. The orrery is inherently a parallel system — just like Hirsel's orchestration.

Delivery is escape velocity

When a spec validates, it achieves escape velocity — breaking free of the route's gravity to be delivered as a PR. The metaphor of leaving orbit maps perfectly to pushing completed work out of the system.
