IC Chip = Spec

Each spec is an integrated circuit on the board. Green LED means validated. Amber pulses for working. Off means pending or draft.

Copper Trace = Task

Tasks are the copper traces connecting ICs. Active traces carry signals. Blocked traces are dashed. The routing reveals task dependencies.

Signal Pulse = Worker

Workers are signal pulses flowing along copper traces. Each pulse carries execution from one IC toward the next, transforming plan into code.

Why this is interesting

Engineers read this instantly

A PCB layout is already a systems diagram. Developers immediately understand that ICs are components, traces are connections, and signals flow between them. The metaphor requires zero explanation for the target audience.

Routing is the hard problem

In PCB design, trace routing is the critical challenge — just like task dependency management in Hirsel. Blocked traces (dashed) show where the system can't flow yet. Via holes show where specs decompose into deeper task layers. The board layout IS the orchestration plan.

Status is hardware-native

LEDs are the most intuitive status indicator ever designed. Green means go. Amber pulsing means working. Off means not powered yet. No legend needed, no learning curve. The board tells you its state the way real hardware does.

Delivery is the edge connector

The edge connector is where the board interfaces with the outside world. Validated signals queue at the connector pins and push out as a PR. The board's purpose is to process signals and deliver them — exactly what a Hirsel route does with specs.
