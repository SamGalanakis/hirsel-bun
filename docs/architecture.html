Hirsel Runtime Architecture

Shepherd-first orchestration with embedded lash execution

1 — Snapshot

The desktop app routes user intent into send_shepherd_message, where Shepherd now spins a real lash-core RuntimeEngine turn. The turn streams incremental events to the UI, executes filesystem/shell tools in a scoped workspace, persists structured chunk history, and supports pasted PNG images through TurnInput.images_png.

3 — Shepherd Chat Runtime (GUI Command Layer)
Session Lifecycle

In-memory session registry

start_shepherd_session allocates UUID sessions. send_shepherd_message enforces active-session checks. stop_shepherd_session emits sessionEnded and clears session state.

Structured Chunks

Strong message contract

Chunk payloads are validated before storage and runtime use.

  • text, thinking, tool, image
  • Image count limit: 8 per message
  • Image payload limit: 12 MiB base64
  • PNG required for runtime image ingestion
Event Translation

lash → Shepherd UI events

Text and code blocks stream as textDelta/thinkingDelta. Tool calls emit paired toolCallStart and toolCallUpdate. Terminal failures propagate error.

4 — Worker Runtime (Embedded lash)
Worker Process

Runtime assembly in worker/lash_runner.rs

  • run_worker builds Session, Agent, and RuntimeEngine
  • Composite tools: fs/search/edit/shell + Hirsel MCP operations
  • OAuth credentials from encrypted credential store or env fallback
  • Event sink records tool/text events into per-run SQLite state
Execution Model

One task context, isolated worker

Workers stay process-isolated and consume assigned tasks from board state. They use MCP operations for task graph mutations, chat, docs, and completion signaling. Orchestration remains separate from worker execution context.

5 — Storage Topology
Global DB

~/.hirsel/hirsel.db

Projects, routes, board nodes, credentials, and Shepherd chunk history.

Run DB

runs/{run}/hirsel.db

Per-run worker events, state machine status, and lifecycle records.

Route Files

projects/{id}/routes/{name}

Route-scoped docs, board task content files, and code snapshots.

Chat History

shepherd_chat_messages

Scope-aware history for general, run, and board conversations.
