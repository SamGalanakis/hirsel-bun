Agent Scopes

Shepherd

User's main point of contact. Orchestrates threads, updates the canvas, queries the knowledge graph via search_context.

Librarian

Async knowledge curator. Receives conversation syncs, extracts durable facts, maintains the graph and project index.

Threads

Isolated workers with their own workspaces. Can query the knowledge graph for project context.

Knowledge Graph Architecture

The knowledge graph is Hirsel's durable project memory — structured facts about architecture, decisions, conventions, and domain, stored in SurrealDB. The Librarian writes; the search_context sub-agent reads; Shepherd and Threads query via search_context.

The Librarian Agent

Persistent agent scoped to a project. Has read/write access to kg_node and kg_edge via SurrealDB record-user permissions. Pure knowledge curation — no file editing, no canvas.

Sync Workflow

After every Shepherd/Thread turn, queue_background_sync() sends the Librarian a transcript. The sync prompt instructs:

  1. Identify what was learned, decided, built, or changed
  2. Query existing nodes related to these topics
  3. Update every relevant node — a single sync touches all affected nodes
  4. Create new nodes only for genuinely new entities
  5. Update document:index if the project landscape changed

Lint (Health Check)

Background worker runs every 30 minutes. Checks: orphan nodes, stale-but-read nodes, unused nodes, missing nodes, weak content, index drift.

search_context Tool

Available to Shepherd and Thread scopes. Takes a natural-language question, spawns a short-lived LLM sub-agent, returns a text answer with [kind:id] citations.

read_by_search_context Tracking

After graph_query or search_graph_text returns results, a background tokio::spawn task bumps read_by_search_context = time::now() on every returned node. This enables:

Stale but valued

read_by_search_context recent, updated_at old. High-value node going stale — needs refresh.

Unused

read_by_search_context null, updated_at old. Nobody needs this — candidate for cleanup.

Canvas

Ephemeral project-scoped document in project_canvas table. Can reference graph nodes via <hirsel-node-ref node="kind:id"> tags. Owned by the Shepherd for real-time updates during conversation.

Runtime Construction

  1. Load LLM settings, resolve provider (Codex or OpenRouter)
  2. Resolve model for scope's RuntimeModelRole
  3. Build SessionPolicy (model, context window, execution mode)
  4. Build RuntimeHostConfig with prompt overrides (scope guidance appended)
  5. Assemble tool plugins via plugin factories + scope-specific custom plugins
  6. Create or resume LashRuntime from state/history
  7. Stream turn via ChannelEventSink → SSE to UI
