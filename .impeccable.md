## Design Context

### Users
Solo developers using Hirsel as their primary daily coding tool. They sit down, open Hirsel, and work with it for hours — managing multiple AI agents across projects. This is a power tool, not a dashboard they glance at. The interface needs to support deep focus sessions while keeping parallel work visible at a glance.

### Brand Personality
**Warm, crafted, intentional** — like a Leica camera or a well-made pen. Every detail should feel considered. Not flashy, not minimal-for-minimal's-sake. Functional luxury: the kind of tool where you notice the quality of the materials and the care in the construction. There's warmth here, not cold tech precision.

### Aesthetic Direction
Fresh direction for v0.4. The rearchitecture (Docker dropped, freeform workspaces, lightweight single binary) calls for a visual language that matches: lighter, more confident, less infrastructure-heavy.

**Tone**: Analog warmth meets digital precision. Think letterpress on good paper, brass instruments, hand-drawn maps with precise measurements. The interface should feel like something a craftsperson would build for themselves — opinionated, efficient, beautiful without trying to be beautiful.

**Theme**: Dark as primary (solo dev, long sessions, often evening work). Light variant for daytime.

**Anti-references**: Generic SaaS dashboards, AI chatbot interfaces with purple gradients, anything that looks like it was generated by AI in 2024. No glassmorphism. No gradient text. No card soup.

### Design Principles
1. **The tool disappears** — Interface serves the work, never competes with it. When the agent is working, the UI should feel like watching through glass.
2. **Density earns its place** — Show information that helps the next decision. Hide everything else. But never hide it so deep the user has to hunt.
3. **Motion is communication** — Animate only to show state change, arrival, or departure. No decoration.
4. **Warm materials** — Tint everything toward warmth. Even dark mode should feel like a well-lit workshop, not a void.
5. **One typeface pairing, used with conviction** — Typography does the heavy lifting. Let it breathe where it matters, compress where density serves.
